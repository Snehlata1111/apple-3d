# 3D Product Experience

An interactive 3D product experience built with React, Three.js, React Three Fiber, GSAP, and Tailwind CSS.

## ✨ Features

- Interactive 3D product model
- Multiple product finishes
- Smooth GSAP animations
- Interactive video carousel
- Responsive design
- Dynamic product sizing
- Scroll-based animations
- Interactive 3D lighting and materials

## 🛠 Tech Stack

- React.js
- Three.js
- React Three Fiber
- React Three Drei
- GSAP
- Tailwind CSS
- Vite

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm

### Installation

Install the project dependencies:

```bash
npm install
```

### Run the Project

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in the terminal.
